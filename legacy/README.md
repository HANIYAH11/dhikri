# أَذْكَار — موقع أذكار الصباح والمساء

موقع عربي (RTL) متكامل لأذكار الصباح والمساء، **بمصادرها**، بتصميم أنيق ومريح للعين، مع **مسبحة مستقلة لكل ذكر متكرّر**.

---

## التشغيل

افتح `index.html` بالنقر المزدوج — الموقع يعمل **مباشرة بلا إنترنت وبلا تنصيب**، لأن الخطوط مُضمَّنة محليًّا.

إن أردت تشغيله عبر خادم محلي (اختياري):

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 8931
# ثم افتح: http://127.0.0.1:8931
```

## المزايا

| الميزة | الوصف |
|---|---|
| **مسبحة لكل ذكر متكرّر** | دائرة عدّ تفاعلية بحلقة تقدّم، مع أزرار «طرح / تصفير / إكمال»، ولا تتجاوز العدد المطلوب |
| **تكبير وتصغير الخط** | ٦ درجات من ٧٩٪ إلى ١٣٧٪، من الشريط العلوي أو لوحة الإعدادات أو لوحة المفاتيح (`+` / `−`) |
| **الثيم** | فاتح / داكن / تلقائي (يتبع نظام الجهاز) — يُحفظ الاختيار |
| **الخط المثمّن** | الخط الافتراضي **Noto Kufi Arabic** — حروفه هندسية مربّعة الزوايا، ويُمكن التحويل إلى خط النسخ (Amiri) |
| **التقدّم** | حلقة نسبة الإنجاز + شريط تقدّم + تصفير تلقائي عند تغيّر اليوم |
| **بحث ذكي** | يتجاهل التشكيل ويوحّد الهمزات (أ/إ/آ، ة/ه، ى/ي) |
| **تصفية** | الكل / المتبقّي / المنجَز / ذو المسبحة |
| **المفضلة** | نجمة لكل ذكر، تُحفظ بين الجلسات |
| **نسخ ومشاركة** | نسخ نص الذكر مع مصدره وحكمه وعدد تكراره |
| **طباعة / تصدير PDF** | كتاب كامل مُزيَّن: ترويسة باسم الموقع وتاريخ ميلادي/هجري، فاصل بين قسمي الصباح والمساء، خانات فارغة للتعقيب بالقلم، وتذييل بالمصادر والتنبيه — أو القسم المعروض فقط |
| **فتح تلقائي** | يعرض أذكار الوقت المناسب حسب الساعة |
| **إمكانية الوصول** | سمات `aria`، تنقّل بلوحة المفاتيح، احترام `prefers-reduced-motion` |

### اختصارات لوحة المفاتيح
- `+` / `-` : تكبير / تصغير الخط
- `t` : تبديل المظهر
- `Esc` : إغلاق لوحة الإعدادات

### تصدير PDF
من الشريط العلوي (`🖨 طباعة`) أو من الإعدادات (`طباعة / حفظ PDF`)، ثم اختر «حفظ كـ PDF» من نافذة الطباعة:

- **الافتراضي**: الكتاب كاملًا (الصباح ثم المساء، وصفحة لكل قسم) — ويمكن تعطيله من خيار «عند الطباعة: الكتاب كاملًا» ليُطبع القسم المعروض فقط.
- صفحة **A4** بهوامش `١٤مم`، ولوحة ألوان فاتحة مُجبرة حتى لو كان المظهر داكنًا.
- ترويسة فيها زخرفة ثمانية + التاريخ الميلادي والهجري + نطاق المطبوع، وتذييل فيه المصادر والتنبيه.
- **مربّعات فارغة** بعد كل ذكر متكرّر (٣، ٤، ٧، ١٠، ١٠٠) للتعقيب بالقلم.
- كل بطاقة كاملة في صفحة واحدة (`break-inside: avoid`)، والنص بحجم مريح مع تشكيل المصدر والحكم بخلفية ملوّنة.

## مصدر الأذكار

النصوص من **القرآن الكريم**، و**البخاري**، و**مسلم**، و**سنن أبي داود**، و**الترمذي**، و**النسائي**، و**ابن ماجه**، و**مسند أحمد**، مع التنبيه إلى مواضع الخلاف كما في **«حصن المسلم»**؛ وقد رُوجعت أرقام الأحاديث وأحكامها على موقع **sunnah.com**، وقُوبلت على بيانات «حصن المسلم».

- **٢٨** ذكرًا لأذكار الصباح، و**٣٠** ذكرًا لأذكار المساء.
- كل ذكر مرفق بـ: **المصدر** (مع رقم الحديث)، **حكمه** (صحيح / حسن / متفق عليه)، و**فضله**.
- **١٤** ذكرًا في كل قسم له مسبحة (٣، ٤، ٧، ١٠، ١٠٠ مرة).
- عند الخلاف في العدد أو التصحيح أو نصّ الذكر ذُكر ذلك صراحةً في حقل «ملاحظة» داخل البطاقة.

> تنبيه: التطبيق للاستذكار والقصد لا لاستنباط الأحكام، والرجوع إلى أهل العلم مفتاح الفهم.
