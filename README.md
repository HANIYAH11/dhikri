# ذِكري — أذكار الصباح والمساء

تطبيق ويب عربي إسلامي (PWA) لأذكار الصباح والمساء، مع مسبحة تفاعلية لكل ذكر،
وتوثيق شرعي لكل نص، وحفظ للتقدّم، وبحث، ومفضلة، وإعدادات ثيم وحجم خط — بتصميم
عربي كامل (RTL) مُهيّأ للجوال أولًا.

> **القاعدة التي بُني عليها المشروع:** جمال التصميم لا يسبق صحة الذكر وتوثيقه.

---

## التشغيل

المتطلبات: Node.js 18+ (اختُبر على Node 24).

```bash
npm install          # تثبيت الاعتماديات
npm run dev          # خادم التطوير: http://localhost:5173
npm run build        # فحص TypeScript + تدقيق قاعدة البيانات ثم البناء في dist/
npm run validate     # تدقيق بنية بيانات الأذكار فقط (دون بناء)
npm run preview      # معاينة نسخة الإنتاج: http://localhost:4173
```

ملاحظات على Windows/PowerShell:

- إن ظهر خطأ `npm.ps1 cannot be loaded` فاستخدم `npm.cmd run build` بدل `npm run build`
  (سياسة تنفيذ السكربتات)، أو اضبط `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- البناء يعمل بمسارات نسبية (`base: "./"`)، فيُرفع المجلد `dist/` كما هو على أي
  استضافة ثابتة (GitHub Pages، Netlify، nginx…) دون ضبط إضافي.

- فرع **`main`** = الكود المصدر (يُرفع بالعادي).

- الروابط نسبية و`base: "./"`، فيعمل الموقع من مجلد فرعي مثل `/dhikri/` دون أي ضبط.

### تحديث الموقع بعد تعديل

**الطريقة الأولى (سكربت):**

```powershell
$env:GH_TOKEN = "ghp_..."   # رمز بصلاحية repo
powershell -ExecutionPolicy Bypass -File scripts/deploy.ps1
```

**الطريقة الثانية (يدويًّا):**

```powershell
npm.cmd run build
# انسخ محتوى dist/ وملف .nojekyll إلى فرع gh-pages ثم:
git push origin gh-pages
```

يُحدَّث الموقع خلال دقيقة تقريبًا من اكتمال الدفع.

### النشر التلقائي مع كل push (اختياري)

لتفعيل GitHub Actions لاحقًا: امنح الرمز صلاحية **`workflow`**، ثم انقل
`deploy-workflow.example.yml` إلى `.github/workflows/deploy.yml`، واضبط
**Settings → Pages → Source: GitHub Actions**. ملاحظة: صلاحية `workflow`
ممنوعة على الرموز المحدودة (fine-grained) — تُستخدم الرموز الكلاسيكية.

## قاعدة بيانات الأذكار (Schema)

كل ذكر في `src/data/raw.ts` بهذا الشكل:

```ts
{
  id: "s-16",                                  // معرّف ثابت
  category: "morning" | "evening",
  order: 16,                                   // ترتيب الظهور
  title: "اللهم إني أعوذ بك من الهم والحزن",   // عنوان اختياري للاستدلال
  count: 1,                                    // عدد التكرار (1 = زر «تم القراءة»)
  text: "اللَّهُمَّ إِنِّي أَعُوذُ ...",        // نص الذكر بالتشكيل
  source: "متفق عليه — صحيح البخاري (2893، و6369)",
  book: "صحيح البخاري",                        // يُشتق تلقائيًّا من source إن لم يُذكر
  hadith_number: "2893، و6369",                // يُشتق تلقائيًّا من source إن لم يُذكر
  authenticity: "صحيح — متفق عليه",            // grade
  benefit: "كان النبي ﷺ يتعوذ ...",            // الفضل (إن ثبت)
  note: "...",                                 // ملاحظة تحريرية عند الخلاف أو التصحيف
  audio: undefined,                            // لا صوت إلا من مصدر موثوق
  is_favorite: false                           // تُدار في Local Storage لا في البيانات
}
```

**قواعد إضافة ذكر جديد:**

1. الصق النص مشكّلًا حرفيًّا من مصدر مطبوع موثوق — لا تعديل ولا اختصار.
2. املأ `source` بنصٍّ فيه اسم الكتاب ورقم الحديث، وسيُستخرج `book` و`hadith_number`
   تلقائيًّا؛ وإن تعذّر الاستخراج تُترك الحقلان فارغين (لا تخمين).
3. لا تكتب فضلًا أو درجةً غير ثابتة؛ إن اختلف العلماء ضِف `note` تُوضح أن المسألة
   ليست قطعية.
4. إن لم تتوفر معلومة اتركها فارغة أو اكتب «غير متوفر».
5. أي نص تجريبي يجب تعليمه `DEMO DATA` صراحةً وعدم تقديمه كمحتوى حقيقي.

## التوثيق الشرعي: ما تمّ وما يجب قبل الإطلاق

**ما تمّ (مراجعة آلية + مباشرة على `raw.ts`):**

- تطابق أغلب أرقام الأحاديث مع نصوصها، وتصحيح المخالف منها:
  صحيح أحمد **15363** (كانت 15563)، وتوثيق البخاري **(6403، و6404)**،
  وإضافة مسلم **2702** مع بيان «المائة في اليوم» مقابل «حصن المسلم في الوردَين».
- حذف عبارات لم يثبت لها سند في الموضع (مثل نسبتين لـ«أفضل الذكر الاستغفار»).
- إثبات ملاحظات الضعف والمقال عند وجودها بدل الإغفال (مثل رواية ابن ماجه الموقوفة
  المقلوبة في دعاء الهمّ والحزن).

**ما يجب فعله قبل النشر الفعلي:**

1. مراجعة النصوص والأرقام كلها على يد مختصّ بالحديث والتخريج (تُعامل البيانات
   حاليًّا كمحتوى قيد التدقيق لا كمرجع نهائي).
2. توحيد رقم الحديث مع الطبعة المعتمدة عندك (الترمذي والنسائي وابن ماجه تختلف
   الطبعات في الترقيم).
3. مراجعة فضائل الأحاديث المشكولة (ضعيف/حسن لغيره) قبل عرضها للقارئ العام.
4. تفعيل الصوت: لا يوجد أي تسجيل صوتي مضمّن؛ لا تُضِف تسجيلًا إلا من مقرئ موثوق
   وإذن موثّق، كما في الإعدادات.

## التخزين والخصوصية

لا خادم ولا حسابات ولا تتبّع؛ كل شيء في `localStorage` على جهاز المستخدم:

| المفتاح | المحتوى |
| --- | --- |
| `dhikri:progress` | التاريخ + المُنجَز + العدّادات + آخر ذكر/قسم + المفضلة |
| `dhikri:settings` | الثيم، حجم الخط، الخط، الصوت، التذكيرات، الاحتفاظ بالعدّادات |

- يُصفَّر الورد تلقائيًّا عند تغيّر اليوم (ويفعل «إعادة الورد» يدويًّا).
- «مسح كل التقدّم» يمسح التقدّم **والمفضلة** بعد ضغطة تأكيد ثانية.
- التذكيرات تعمل **ما دام تبويب الموقع مفتوحًا فقط** — وهذا مكتوب حرفيًّا في الواجهة.

## الإتاحة والتصميم

- RTL كامل، Mobile-First: ملاحة سفلية (5 عناصر) على الجوال، وشريط علوي على المكتب.
- لوحة المفاتيح وقارئات الشاشة: أهداف `focus` واضحة، `aria-label` لكل زر أيقوني،
  حالات `aria-pressed` / `role="switch"` / `role="progressbar"`، منطقة `role="status"`
  تعلن «أحسنت، أتممت الذكر.»، ونقل التركيز لبطاقة «التالي ←».
- لا يُعتمد على اللون وحده (الأيقونات والنصوص والأرقام تحمل المعنى).
- `prefers-reduced-motion` مدعوم، والحركة محدودة جدًّا (شريط تقدم، ظهور البطاقة).
- تباين يتجاوز معيار WCAG AA في الوضعين الفاتح والداكن.
